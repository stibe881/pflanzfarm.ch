# pflanzfarm.ch

Website, Online-Shop und Verwaltung der Pflanzfarm Steinmann, Ebersecken.

- `backend/` – Laravel 12 mit Filament-Adminbereich, Kundenkonten, Bestellungen, Stripe (Karte/TWINT), Resend (E-Mails), Rechnungen mit Swiss-QR-Code
- `frontend/` – Quellcode der Website; `npm run build` erzeugt die Dateien in `backend/public`

Installation, Konfiguration und Betrieb: siehe [DEPLOY.md](DEPLOY.md).
